# 时间校准实验

这是离线研究入口。它校准完整线上算法的最终点预测误差，不修改线上预测日期、邮箱提醒或部署模型权重。

## 运行

```bash
cd wishindiary-api
python scripts/backtest.py --synthetic-only --calibrate-intervals
```

报告仍写入 `MODEL_PATH` 同目录的 `forecast_evaluation_report.json`，新格式为 schema 2；管理端同时兼容原有 schema 1。用 `--output-dir` 可以把实验报告放在独立目录，管理端只读取固定模型目录中的报告。默认不读取用户数据库，也不需要 SMTP。

默认按候选预测起点的约 60% / 20% / 20% 设置训练、校准、测试日期边界。同一天不会跨段；周期完成时间会进一步减少可用标签，所以实际样本数量不一定符合这个比例。报告记录实际日期、可用标签时间和样本量。

可以提前固定两个日期，便于复现实验：

```bash
python scripts/backtest.py --synthetic-only --calibrate-intervals \
  --calibration-cutoff 2024-06-26 --test-cutoff 2024-08-18
```

授权 CSV / 数据库入口也接受这些参数；授权条件和标准周期表格式见 [完整流程回测](RESEARCH_BACKTEST.md)。不要根据当前测试结果反复选择边界、目标或参数后，把同一测试段作为独立验证。

## 三段协议

| 阶段 | 可用数据 | 用途 |
| --- | --- | --- |
| 训练 | 预测起点早于校准开始，且目标在校准开始前或当天完成 | 拟合全局 RF，随后冻结 |
| 校准 | 起点位于校准段，且目标在测试开始前或当天完成 | 计算每条预测路径的绝对误差与固定半径 |
| 未来测试 | 起点不早于测试开始；每次只使用当时已完成的个人历史 | 评估冻结模型与校准器，测试标签不参与拟合 |

既有用户仍需在全局训练中出现。模型未见用户按用户分组留出：每折测试用户同时从全局训练和校准中排除，允许使用其预测时已知的个人历史。RF 在校准开始前冻结，不在校准结束后重训，避免校准半径与预测器不一致。

RF 个性化路径和基础统计路径分别校准，不把两条路径的残差混在一起。误差来自与 API 相同的历史过滤、个人均值收缩、取整及 21–45 天点预测。

## 区间与指标

预设覆盖目标为 90%。对每条路径，取 `n` 个校准绝对误差的第 `ceil((n + 1) × 0.9)` 小值作为半径，区间为最终点预测 ± 半径，不做插值。当阶数超过 `n` 时不输出有限区间：90% 目标至少需要 9 个该路径的已完成校准样本，这只是计算门槛，不是充分的可靠性证据。

区间端点不沿用点预测的 21–45 天裁剪，以免人为删除可能的真实结果。范围外的正数标签仍参与校准和评估。区间只用于研究报告，不能直接解释为医学正常范围。

管理端展示每折校准样本范围、可用折数、可校准/无法校准的未来样本量，以及覆盖率和平均宽度。原始区间与校准区间只在两者都可用的同一批测试样本上配对比较；若有缺少原始区间的样本，另外展示全部可校准样本的指标。空组不生成指标，零半径或零宽度正常显示。

算法源文件摘要包含校准代码。报告缺失、过期、时间边界错误、样本数不一致或非法指标均有明确状态；接口只返回汇总，不返回残差、用户编号或原始记录。

## 合成演示结果

2026-10-01 的演示使用 30 个模拟用户、300 条周期；校准开始为 2024-06-26，测试开始为 2024-08-18。全局模型只使用校准开始时已完成的标签。既有用户的 RF 校准有 26 条记录；未见用户每折有 20–22 条，5 折均可用。每种协议有 54 条未来 RF 样本。

| 协议 | 原始覆盖率 | 校准覆盖率 | 原始平均宽度（天） | 校准平均宽度（天） |
| --- | ---: | ---: | ---: | ---: |
| 既有用户 | 27.78% | 90.74% | 1.9911 | 6.0000 |
| 模型未见用户 | 25.93% | 94.44% | 1.9530 | 6.4074 |

以上为同一冻结模型、同一未来样本的区间对比；覆盖上升伴随区间变宽。点预测 MAE 为 1.7778 / 1.7593 天。基础统计路径没有校准或测试样本，不能据此判断冷启动区间效果。

这次模型在 60% 边界附近冻结，原先两段回测在 80% 边界附近冻结，使用的训练标签不同。不能把两个实验的点预测指标差异解释为校准提高或降低了点预测准确率。

## 限制与下一步

经典 split conformal 的覆盖保证依赖 IID / 可交换性；同一用户的周期相关、用户之间不同、时间变化和逐步更新的历史特征都影响这些条件。因此 90% 是实验目标，演示中的经验覆盖率不构成真实用户或个体的可靠保证。合成数据只验证流程；真实迟填/改写记录还需首次签发快照独立观察。

下一步优先用独立授权数据和新的未来时间段复核，探索波动分组与跨时间稳定性，同时考察区间宽度。未有足够证据前不把校准器接入线上预测或通知。

方法依据：

- [Angelopoulos & Bates：Conformal Prediction 入门，§1.1](https://arxiv.org/html/2107.07511v6#S1.SS1)：校准阶统计量和 IID 条件。
- [Barber & Pananjady：时间相关性下的 split conformal](https://proceedings.mlr.press/v313/barber26a.html)：有历史记忆的时序预测与覆盖损失。
