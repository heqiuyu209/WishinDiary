# 完整预测流程的前瞻回测

先用演示数据生成汇总报告，不需要连接数据库或部署 SMTP：

```bash
cd wishindiary-api
python scripts/backtest.py --synthetic-only
```

结果写入 `MODEL_PATH` 同目录的 `forecast_evaluation_report.json`。可用 `--output-dir` 指定实验目录；管理端只读取默认固定位置。回测在内存训练评估所需的模型，不替换部署权重，也不写预测日志。报告只含汇总、数据摘要、代码/依赖版本与算法源文件摘要。

## 评估协议

- **既有用户**：在公共日历截点之前已经进入全局 RF 训练的用户，逐周期预测截点之后的结果。
- **模型未见用户**：按用户分组留出；每折只用其他用户在截点前已完成的训练标签。未见用户可以使用预测时已知的个人历史，不能解读为完全没有记录的新账号。
- RF 截点后冻结。个人历史随周期完成更新，只包含 `start_date + cycle_length <= 预测起点` 的已知长度；被评估周期的长度与出血天数不能进入该次预测。
- 离线回放假设既往记录当时已可用；真实用户迟填或改写记录的效果，应使用线上首次签发快照独立观察。
- 线上 ML 路径复用最近 50 条查询后的过滤、至少 4 条有效历史、个人均值收缩（K=4）、取整和 21–45 天裁剪。不足 4 条时复用线上基础统计逻辑。
- 均值/中位数使用同一历史的最近三次，指数平滑固定 α=0.5。四种方法在同一批样本上比较，均取整并裁剪；参数不是根据测试集选择的。
- MAE、RMSE、±2/3 天命中率和偏差分别汇总；正偏差表示预测偏晚。按历史条数、已知历史波动与出血天数缺失比例分组，并展示样本量；空组不会生成指标。
- 树分位区间与基础统计区间分别计算实际覆盖率及平均宽度。树间预测分布不等于经过校准的 90% 预测区间，基础统计区间也没有名义 90% 保证。

## 授权数据

演示指标不能证明真实效果。只有获得独立授权后，才使用以下入口：

```bash
python scripts/backtest.py --csv /path/to/authorized_cycles.csv
python scripts/backtest.py --database
```

CSV 必须包含 `user_id,start_date,cycle_length,bleeding_days`；ID 为正整数，开始日为真实日历日期，缺失出血天数留空。重复日期或无效日期会报错；不把用户编号、记录或文件路径写入报告。未知周期长度没有评估标签；正数范围外标签保留在评估中，避免只报告容易预测的周期。

不能把没有实际日历日期的数据随意构造为日历时间后，宣称获得真实时间验证。本入口与现有训练脚本的 Fehring CSV 格式不同，需要真实日期的标准周期表。

## 解读与下一步

报告评估算法流程及折内重新训练的模型；它不是当前部署模型文件的直接测量。页面会核对算法源文件摘要，代码改变后提示重新生成。历史 RF 离线报告与完整流程报告分别展示，不能跨协议拼接成准确率提升结论。

若区间覆盖率低，下一步使用独立的时间校准段扩展或校准区间，再在未使用的未来测试段复核。若复杂模型未超过基线，优先实验个人历史权重、窗口长度和稳定基线；保留同一评估协议并记录实验参数。最终模型选择与真实效果需要独立授权的数据和后续部署观测。

独立时间校准实验现可用 `--calibrate-intervals` 启用；它预留训练、校准、未来测试三段，默认目标为 90%，分别校准 RF 和基础统计的点预测绝对误差。管理端同时展示原始/校准区间的配对覆盖率、宽度和样本不足状态。实验不会替换线上区间或模型，步骤与限制见 [时间校准实验](INTERVAL_CALIBRATION.md)。

## 合成示例的流程验证

2026-10-01 的演示回测使用 30 个模拟用户、300 条周期，日历截点为 2024-08-18；每种协议比较同一批 54 条未来周期。以下只是合成数据上的流程检查，不能据此推断真实用户效果，也不能和历史离线 RF 指标跨协议比较。

| 方法 | 既有用户 MAE（天） | 模型未见用户 MAE（天） |
| --- | ---: | ---: |
| 完整线上算法 | 1.6481 | 1.6667 |
| 最近三次均值 | 1.9630 | 1.9630 |
| 最近三次中位数 | 2.0370 | 2.0370 |
| 指数平滑（α=0.5） | 1.8519 | 1.8519 |

树分位区间实际覆盖率分别为 33.33% 和 35.19%，平均宽度约 1.95 和 2.05 天。这个结果说明必须单独研究区间校准；点预测误差较小，不能作为区间可靠的依据。新增三段校准实验使用更早的模型冻结日期，与这里的两段回测分开解读。
