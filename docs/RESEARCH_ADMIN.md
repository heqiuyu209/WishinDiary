# 研究管理端

入口：登录后进入 `/admin/research`。普通账号不会显示入口，服务端接口也会返回 403。

## 授权已有账号

默认没有管理员。部署者先创建账号，再通过本人会话 `/api/v1/auth/session` 的 `user_id` 或数据库查询确认 ID；配置后重启 API：

```dotenv
ADMIN_USER_IDS=1,5
```

本地配置写入 `wishindiary-api/.env`，Docker Compose 配置写入仓库根目录 `.env`。必须替换成实际已有账号 ID；注册接口不能申请管理员权限。

## 展示与评估

- 数据页只有全局汇总：完整周期、范围外/缺失记录、历史充分度、长度分布和当前特征可构造样本数。
- 提醒页只展示发送状态总数，用于发现待核查任务，不展示收件人或健康日期。
- 不返回用户名、邮箱、用户 ID、日记或同房记录，不支持导出原始记录或在线训练。
- 评估读取 `MODEL_PATH` 同目录的 `model_evaluation_report.json`，缺失/无效时显示明确状态，不生成虚构指标。
- 分用户验证用于新用户泛化；时间留出用于未来预测。RF 和均值基线在同一五折协议比较；线上收缩后的完整流程仍需独立回测。
- 页面提示合成数据来源，并核对评估报告的模型摘要与当前模型文件。

生成演示评估（不读取用户数据库）：

```bash
cd wishindiary-api
python scripts/train.py --synthetic-only
```

真实数据训练使用已有训练脚本和独立授权数据流程，管理端汇总不会自动用于训练。
